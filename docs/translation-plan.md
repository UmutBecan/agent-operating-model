# Translation plan

English is the primary language and the source of truth. Turkish is the second language.

1. Translate README first as `README.tr.md`, with a link from the English README.
2. Then `FAQ.md` and the templates, one file at a time, as `<name>.tr.md`.
3. Keep commands, file names, header names and code unchanged; translate prose only.
4. A translation is only merged if the English version it was made from is named in its first line (commit or date), so drift is visible.
5. Contributions in other languages are welcome after Turkish, under the same rule.

Status: not started (planned).
